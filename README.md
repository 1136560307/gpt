# DR.JOO 俏博士 React 企业官网

这是俏博士 DR.JOO 企业官网 React + Vite 版本，已替换原 gpt 仓库内容。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

- Vercel / Netlify：Build Command 使用 `npm run build`，Output Directory 使用 `dist`
- 宝塔 / Nginx：上传 `dist` 目录，并将路由回退配置到 `index.html`

## 页面模块

- 科技感首页首屏
- 品牌信任与连锁运营沉淀
- 品牌资质与证据链
- 门店形象展示
- 头皮护理体系
- 产品矩阵
- 总部扶持与加盟转化
- AI 门店赋能
- 新闻资讯
- 联系留资表单
